# Starter Board

A plain HTML/CSS/JS starter project for the BCA CS Camp 2026 hackathon.

## Topic

The app is a customizable item board. Students can add items, mark them done, and earn points. You can turn it into a study tracker, club matcher, scavenger hunt, habit builder, game tracker, school guide, or anything else.

## Files

- `index.html` holds the page structure.
- `style.css` controls the layout and colors.
- `script.js` stores the app data and makes the buttons work.

## Beginner extension ideas

- Change the starter items.
- Add more categories.
- Give each category a different color.
- Add a delete button for every item.
- Save items with `localStorage` so they remain after refreshing.
- Add difficulty levels.
- Add filters for completed and incomplete items.
- Change the theme to match a team's project idea.

## How to run

You do not need to install anything. This project uses only HTML, CSS, and JavaScript.

### Option 1: Open the file directly

1. Find the project folder on your computer.
2. Double-click `index.html`.
3. The app should open in your web browser.

If you make changes, refresh the browser page to see them.

### Option 2: Use VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click inside the file.
4. Click `Open with Live Server`.

If you do not see `Open with Live Server`, install the VS Code extension called `Live Server`.

### What each file does

- Edit `index.html` to change the text and page structure.
- Edit `style.css` to change colors, spacing, and layout.
- Edit `script.js` to change how the app works.

### Troubleshooting

- If the page looks plain, make sure `style.css` is in the same folder as `index.html`.
- If buttons do not work, make sure `script.js` is in the same folder as `index.html`.
- If changes do not show up, refresh the browser page.
